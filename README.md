# Friendz Auto Sales: Website

The public website for **Friendz Auto Sales**, a car dealership in Richmond, British Columbia.

**Live site:** https://friendzautoweb1.vercel.app

## Features

- Vehicle listings loaded live from the dealership's database
- Mobile-first design, installable as a Progressive Web App (offline shell via a service worker)
- Admin page with secure sign-in (Supabase Auth) for managing listings

## Tech stack

HTML, CSS and JavaScript (no framework) · Supabase · Vercel
